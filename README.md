# QuickPDF

Small, lightweight PDF utilities for everyday tasks.

QuickPDF is an experimental web project focused on making common
PDF operations easier without complicated interfaces.

## Current tools

- PDF file inspection
- Page count
- File size display
- Basic file validation

## Planned

- Merge PDFs
- Split pages
- Rotate pages
- Reorder pages
- Compress exports

## Status

Early prototype. Features may change.

## Tech stack

- Next.js
- TypeScript
- pdf-lib
